caustics

class caustics.CausticDetector(rays, dimension)[source]

Bases: object

Detect and classify caustics in ray families.

Caustic types: - Fold (A2): Generic 1-parameter family, corrected by Airy function - Cusp (A3): Generic 2-parameter family, corrected by Pearcey function - Swallowtail (A4): More degenerate, requires higher corrections

compute_maslov_index(ray)[source]

Compute Maslov index: number of caustics crossed × π/2.

The Maslov index accumulates phase jumps at caustics.

detect_caustics(threshold=0.001)[source]

Detect caustics by analyzing Jacobian of ray mapping.

Caustic occurs when ∂(x,y)/∂(ray_param, t) = 0

static airy_uniform(z)[source]

Airy function Ai(z) for fold caustic correction.

Near a fold caustic, the WKB solution is replaced by: u(x) ≈ A(x) · Ai((x-x_c)/ε^{2/3}) · exp(iS(x)/ε)

static maslov_phase_shift(n_caustics)[source]

Phase shift from Maslov index.

Each caustic crossed adds π/2 to the phase.

static pearcey_approx(x, y)[source]

Approximate Pearcey function using asymptotic expansion. Faster but less accurate than full integration.

static pearcey_integral(x, y)[source]

Pearcey integral for cusp caustic (A3 singularity).

P(x,y) = ∫_{-∞}^{∞} exp(i(t^4 + xt^2 + yt)) dt

This is more complex and typically requires numerical integration. Simplified implementation using stationary phase.
